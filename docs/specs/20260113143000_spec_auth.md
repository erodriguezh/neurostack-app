## Overview

The Auth feature implements passwordless magic link authentication using Supabase Auth. It manages the complete authentication lifecycle including sign-in, session persistence, offline support, and user recovery.

**Key Capabilities:**
- Magic link (OTP) authentication via email
- Offline-first with cached user fallback
- Automatic user recovery when auth record exists but user record is missing
- Reactive auth state management via `ValueNotifier`
- Deep link handling for magic link callbacks

## Auth States

### Sealed State Hierarchy

| State | Description | Data |
|-------|-------------|------|
| `AuthUnknown` | Initial state during app startup | None |
| `Unauthenticated` | No active session | None |
| `Authenticating` | Auth operation in progress | None |
| `AuthenticatedOnline` | Active session with network | `User` entity |
| `AuthenticatedOffline` | Active session, no network | Cached `User` entity |
| `OfflineNoUser` | No network, no cached user | None |

### State Transitions

```
App Launch → AuthUnknown
         ↓
    [init() called]
         ↓
    ┌────┴────────────────────────┐
    │                             │
    ▼                             ▼
Has Session?              No Session
    │                             │
    ▼                             ▼
[rehydrate]              Unauthenticated
    │                             │
    ▼                             ▼

    │                             │
    ▼                             ▼

    │                             │
    ▼                             ▼
AuthenticatedOffline     [callback received]
                                  │
                                  ▼
                         AuthenticatedOnline
```

## Business Rules & Invariants

### INV-A1: Single Auth State Source of Truth
- `AuthService.authState` is the single `ValueNotifier<AuthState>` for the entire app
- All auth state changes flow through `AuthService`
- Views react via `ValueListenableBuilder`

### INV-A2: Recovery Upsert on Missing User
- If a user authenticates but their `User` record is missing from the database:
  - System creates a new `User` with trial enabled
  - Uses `ignoreDuplicates: true` to handle race conditions
  - Logs recovery event with environment tag

```dart
// user_bootstrap_service.dart - Recovery mechanism
final result = await _userBootstrapService.rehydrateFromRemote(
  userId: session.user.id,
  authCreatedAt: authCreatedAt,
);
```

### INV-A3: Offline-First User Caching
- `CachedUserStore` persists user to `SharedPreferences` as JSON
- On network loss, app transitions to `AuthenticatedOffline` with cached user
- On reconnection, app rehydrates from remote and updates cache

### INV-A4: Magic Link Rate Limiting
- 60-second cooldown enforced client-side after sending
- Server-side rate limiting detected via 429 status or "rate limit" in error message
- User notified via toast on rate limit hit

### INV-A5: Auth Email Persistence
- Email entered on auth screen saved to `NavigationIntentStore`
- Displayed on check-email screen for user confirmation
- Cleared on successful authentication

### INV-A6: Recent User Detection
- Users created within 5 minutes of auth timestamp are flagged as "recently created"
- Used to differentiate new users from returning users for analytics/UX

### 1. AuthService (`lib/features/auth/data/auth_service.dart`)

**Purpose:** Core authentication orchestration

**Key Responsibilities:**
- Manages `ValueNotifier<AuthState>` lifecycle
- Listens to Supabase `onAuthStateChange` stream
- Handles connectivity changes for online/offline transitions
- Orchestrates user bootstrapping with recovery

**Critical Methods:**

```dart
// Initialize auth - call once at startup
Future<void> init() async {
  _listenToConnectivityChanges();
  _listenToAuthChanges();
  await _rehydrateFromSession();
}

// Sign out and clear state
Future<void> logout({bool forceOnboarding = false}) async {
  await _navigationIntentStore.setForceOnboarding();
  await _dataSource.auth.signOut(scope: SignOutScope.local);
  await _cachedUserStore.clearUser();
  await _navigationIntentStore.clearIntendedRoute();
  await _navigationIntentStore.clearAuthEmail();
  _userBootstrapService.invalidatePresenceCache();
  _currentUser = null;
  authState.value = const Unauthenticated();
  _routerService.replaceAll([Path(name: '/onboarding')]);
}
```

**Auth Change Handler:**

```dart
void _handleAuthChange(AuthChangeEvent event, Session? session) {
  switch (event) {
    case AuthChangeEvent.signedIn:
      if (session != null) _rehydrateFromSession(session: session);
    case AuthChangeEvent.signedOut:
      _currentUser = null;
      authState.value = const Unauthenticated();
    case AuthChangeEvent.tokenRefreshed:
      // Session refreshed, no state change needed
    case AuthChangeEvent.userUpdated:
      // User metadata updated
    default:
      break;
  }
}
```

### 2. UserBootstrapService (`lib/features/auth/data/user_bootstrap_service.dart`)

**Purpose:** User data retrieval and recovery during authentication

**Key Method:**

```dart
Future<Either<DomainFailure, UserBootstrapResult>> rehydrateFromRemote({
  required String userId,
  required DateTime authCreatedAt,
}) async {
  // Try to fetch existing user
  final fetchResult = await _userRepository.getUserById(userId);

  return fetchResult.fold(
    (failure) async {
      // User not found - attempt recovery upsert
      final newUser = User.createWithTrial(
        id: userId,
        createdAt: authCreatedAt,
      );

      final upsertResult = await _userRepository.upsertUser(
        newUser,
        ignoreDuplicates: true,
      );

      return upsertResult.map((user) => UserBootstrapResult(
        user: user,
        didRecoverUpsert: true,
      ));
    },
    (user) => Right(UserBootstrapResult(
      user: user,
      didRecoverUpsert: false,
    )),
  );
}
```

### 3. CachedUserStore (`lib/features/auth/data/cached_user_store.dart`)

**Purpose:** Local user persistence for offline support

```dart
class CachedUserStore {
  static const _key = 'cached_user';

  Future<void> saveUser(User user) async {
    final dto = UserDto.fromDomain(user);
    await _prefs.setString(_key, jsonEncode(dto.toJson()));
  }

  Either<DomainFailure, User?> loadUser() {
    final json = _prefs.getString(_key);
    if (json == null) return const Right(null);

    return UserDto.fromJson(jsonDecode(json)).toDomain();
  }

  Future<void> clearUser() async {
    await _prefs.remove(_key);
  }
}
```

### 5. CheckEmailViewModel (`lib/features/auth/presentation/check_email_view_model.dart`)

**Purpose:** Handles email verification screen logic

**Key Features:**
- 60-second resend cooldown with countdown timer
- Rate limit detection and user notification
- Email persistence across screen transitions

```dart
Future<void> resendMagicLink() async {
  if (!canResend) return;

  final targetEmail = email.value?.trim();
  if (targetEmail == null || targetEmail.isEmpty) {
    _notifyService.setToastEvent(
      ToastEventError(message: Translate.current.authMissingEmail),
    );
    return;
  }

  _isSending = true;
  _startCooldown(60);

  try {
    await _dataSource.auth.signInWithOtp(
      email: targetEmail,
      emailRedirectTo: _redirectUrl(),
    );
  } on AuthException catch (error) {
    if (_isRateLimited(error)) {
      _notifyService.setToastEvent(
        ToastEventWarning(message: Translate.current.authRateLimited),
      );
    } else {
      _notifyService.setToastEvent(
        ToastEventError(message: error.message),
      );
    }
  } finally {
    _isSending = false;
  }
}

bool _isRateLimited(AuthException error) {
  return error.statusCode == '429' ||
         error.message.toLowerCase().contains('rate limit');
}
```

## Startup Integration

### Initialization Order

1. `OnboardingStore.init()` - Check onboarding completion
2. `RouterService.setOnboardingGuard()` - Configure onboarding redirect
3. `AuthService.init()` - Bootstrap auth state
4. Route based on auth state:
   - `OfflineNoUser` → Show offline UI
   - `Unauthenticated` → `/auth`
   - `AuthenticatedOnline/Offline` → Home

```dart
// startup_view_model.dart
final authService = locator<AuthService>();
await authService.init();

if (authService.authState.value is OfflineNoUser) {
  appStateNotifier.value = const OfflineNoUserState();
  return;
}

appStateNotifier.value = const AppInitialized();

if (routerService.shouldShowOnboarding()) {
  routerService.replaceAll([Path(name: '/onboarding')]);
} else if (authService.authState.value is Unauthenticated) {
  routerService.replaceAll([Path(name: '/auth')]);
}
```

## Error Handling

### Auth Exceptions

| Scenario | Handling |
|----------|----------|
| Invalid email format | Client-side validation via `email_validator` |
| Rate limited (429) | Toast warning, cooldown enforced |
| Network error | Falls back to cached user if available |
| User record missing | Recovery upsert creates new user |
| Session expired | Routes to `/auth` |

### Domain Failures (User-related)

| Code | Description |
|------|-------------|
| `User.ProtocolLimitReached` | Free tier protocol limit |
| `User.OnboardingNotCompleted` | Onboarding gate violation |
| `User.AlreadyOnboarded` | Duplicate onboarding attempt |
